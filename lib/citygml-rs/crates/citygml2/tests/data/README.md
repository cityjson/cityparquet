# Test data

Real CityGML 2.0 wherever a real file shows the behaviour under test.

| File                                | Source                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `plateau/`                          | [PLATEAU](https://www.mlit.go.jp/plateau/) Chiyoda-ku 2025 (`13101_chiyoda-ku_pref_2025_citygml_1_op`), one file per object type, unmodified, at the path the archive gives it (`udx/<type>/`), with the i-UR ADE schemas the files name by a relative path (`schemas/iur/{uro,urf}/3.2/`). The `ubld` file holds a `uro:UndergroundBuilding`, which the `uro` schema substitutes for a building. The `urf` file holds only `urf:` ADE classes, which the reader reads as objects of the ADE's class. MLIT, under the [PLATEAU site policy](https://www.mlit.go.jp/plateau/site-policy/), which is compatible with CC BY 4.0. |
| `3dbag/delft_100.city.jsonl`        | The header and first 100 features of the [3DBAG](https://3dbag.nl) v2024.04.20 CityJSONSeq tile `cityparquet-rs` takes as `delft.city.jsonl`: CityJSON that no CityGML was converted to, with LoDs 1.2, 1.3 and 2.2 and attributes holding null. 3DBAG, CC BY 4.0.                                                                                                                                                                                                                                                                                                                                                            |
| `oracle/*.city.jsonl`               | `citygml-tools to-cityjson -l` (citygml-tools 2.5.0) on the file of the same name, the oracle `tests/oracle.rs` compares against.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `schemas/citygml/2.0/`              | The official CityGML 2.0 XML Schemas, as citygml4j 3 bundles them, that the writer's tables are checked against. OGC, under the [OGC software licence](https://www.ogc.org/ogc/software).                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `railway_trees_fragment.gml`        | What `citygml-tools from-cityjson` (citygml-tools 2.5.0) writes from cityjson.org's LoD 3 Railway (`lod3_railway.city.json`, after the KIT/IAI Railway reference dataset, free for unrestricted use), cut to the CityObjectGroup, the fifteen trees whose `ImplicitGeometry`s place three relative geometries, and the CityModel-level appearance. Its oracle is `citygml-tools to-cityjson -l --no-material-defaults`, so a material keeps only what the file states.                                                                                                                                                        |
| `plateau_trk_fragment.gml`          | Three `tran:Track` members cut from a PLATEAU transportation file.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `lod4_building_v2.gml`              | The SIG3D CityGML 2.0 LoD 4 sample building, with a TIN relief.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `b1_lod2_cs_w_sem.gml`              | libcitygml's sample of a building whose LoD 2 CompositeSolid is tagged by xlinked boundary surfaces.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `building_citymodel_appearance.gml` | Hand-written: a building whose material and texture are declared at the CityModel level, after the building, which no real file at hand does.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
