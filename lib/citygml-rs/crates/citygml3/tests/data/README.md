# Test data

Real CityGML 3.0: the `citygml2` crate's files upgraded by citygml-tools, and
the OGC's CityGML 3.0 samples.

| File                                                                         | Source                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ---------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `plateau/`                                                                   | `citygml-tools upgrade -l -s -r` (citygml-tools 2.5.0) on the `bldg`, `tran`, `veg` and `brid` files of the `citygml2` crate's `plateau/udx/`: [PLATEAU](https://www.mlit.go.jp/plateau/) Chiyoda-ku 2025, MLIT, under the [PLATEAU site policy](https://www.mlit.go.jp/plateau/site-policy/), which is compatible with CC BY 4.0. citygml-tools drops the i-UR ADE content it has no module for.                                                                                                                                                                                |
| `lod4_building_v2.gml`, `b1_lod2_cs_w_sem.gml`, `railway_trees_fragment.gml` | The same upgrade of the `citygml2` crate's files of the same name (see its README for their sources).                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `oracle/*.city.jsonl`                                                        | `citygml-tools to-cityjson -l` (citygml-tools 2.5.0) on the file of the same name, the oracle `tests/oracle.rs` compares against; `railway_trees_fragment`'s with `--no-material-defaults`, so a material keeps only what the file states.                                                                                                                                                                                                                                                                                                                                       |
| `ogc/`                                                                       | Unmodified files from the OGC's [CityGML-3.0Encodings](https://github.com/opengeospatial/CityGML-3.0Encodings) (commit `910208e`, MIT licence), under `Moved_to_CITYGML-3.0Encoding_CityGML/Examples/`: `Building/BuildingUnits_Storeys_xlink.gml`; the Melbourne Open Data road section `Transportation/Real-world examples/CityGML_3.0_transportation_data_from_Open_Data_Portal_Melbourne/citygml3_individual_section_1carriageway.gml`; and `ADE-examples/Test-ADE/` and `ADE-examples/Urban-Planning-ADE/`, each a dataset with the ADE schema it names by a relative path. |
