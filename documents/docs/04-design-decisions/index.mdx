This section records **why** CityParquet is designed the way it is. The
[Specification](/specification) records _what_ the format is; where the two
overlap, the specification is authoritative on the _what_ and this section
explains the _reasoning_. Prior art weighed throughout: PostGIS, GeoParquet,
Apache Iceberg, and 3DCityDB.

## How to read a decision

Each decision follows the same shape:

- **Decision** — the one-line resolution.
- **Alternatives considered** — the options weighed, so the choice is positioned.
- **Why this** — the reasoning that selected it.
- **Trade-off** — the cost knowingly accepted.
- **Status** — <Badge variant="success">decided</Badge> or <Badge variant="warning">open</Badge>.

Open items link to [Open questions](/open-questions).
