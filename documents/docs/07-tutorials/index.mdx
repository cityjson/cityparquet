Explained, task-oriented walkthroughs. For the bare copy-paste path, see
[Getting started](/getting-started).

Three take one tool and one local file each. The rest work on the
[published datasets](/resources/datasets) **on object storage**: 3DBAG at national
scale; PLATEAU's Tokyo, in geographic coordinates, with its land use; finding
packages in the STAC catalogue and querying many at once; joining city models to
Overture Maps; and LoD3 façade semantics.

If you would rather not install anything first, the [SQL playground](/playground)
runs DuckDB and both extensions in your browser, against a 16.4 GB 3DBAG package on
object storage.
