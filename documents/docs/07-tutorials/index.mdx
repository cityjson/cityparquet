Explained, task-oriented walkthroughs. For the bare copy-paste path, see
[Getting started](/getting-started).

Choose a tool: **DuckDB** for SQL conversion, **Python** for a small analysis
script, or **Rust** for library reads and writes and CLI conversion. The DuckDB
3D link opens the extension’s own documentation.

**With actual cities** brings the tools together on
[published datasets](/resources/datasets): national-scale 3DBAG, PLATEAU Tokyo,
catalogue queries, joins with Overture Maps, and LoD3 façade semantics.

If you would rather not install anything first, the [SQL playground](/playground)
runs DuckDB and both extensions in your browser, against a 16.4 GB 3DBAG package on
object storage.
